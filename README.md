# Build From Source

## Requirements

- Node.js 20+
- Rust
- Cargo
- Tauri CLI

Clone the repository

```bash
git clone https://github.com/dhanush-devx/Zen-profile.git

cd Zen-profile
```

Install dependencies

```bash
npm install
```

Run development mode

```bash
npm run tauri dev
```

Build for your platform

```bash
npm run tauri build
```

# Why Zen Profile?

Zen Browser already includes profile support, but creating or switching profiles requires opening the browser and navigating through its settings.

Zen Profile is a lightweight native companion that lets you:

- Launch profiles instantly
- Create new profiles
- Rename existing profiles
- Personalize profiles with avatars

All without opening Zen Browser first.
